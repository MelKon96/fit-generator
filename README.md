🥗 FitGen — Умный генератор рациона на базе генетического алгоритма
FitGen — это интерактивное приложение для контроля питания, которое не просто считает калории, а использует принципы эволюционной математики для подбора идеального меню.

🚀 Основные возможности
Персональный расчет: Сайдбар для мгновенного вычисления нормы КБЖУ (калории, белки, жиры, углеводы) на основе параметров пользователя.

Интеллектуальная генерация: Подбор рациона из 15+ продуктов за доли секунды.

Генетический алгоритм: Приложение «выращивает» идеальный план питания, проходя через сотни поколений эволюции (отбор, скрещивание, мутации).

Реактивный интерфейс: Мгновенный поиск, фильтрация по категориям и плавная анимация корзины с помощью Framer Motion.

Полная типизация: Весь проект написан на TypeScript с использованием строгих правил для максимальной надежности.

🛠 Технологический стек
Frontend: React 18

Язык: TypeScript (Strict mode)

Стили: Tailwind CSS

Анимации: Framer Motion

Сборка: Vite
